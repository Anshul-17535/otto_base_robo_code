📱 Screen Ticker
Type a message and tap Show — it sits still on the bottom bar of Bob's screen for 5 seconds. Longer than 26 characters and it is split into pages that swap every 1.5 s. Then the bar goes back to showing the IP. The top bar always shows BOB and the WiFi icon (bright = joined the router, dim with a red slash = not).

Step Speed (ms) 600
Hip Swing (°) 25

⚙ Motor Control
Move each motor independently. 90° = natural centre — motors move equal angles clockwise and anti-clockwise from there.
Calibrate → 90° sends all four to their true neutral instantly.
Horn Positioning (assembly only)
Press Hold Raw 90° before attaching horns — all servos go to exactly 90° with no trim, true mechanical centre.
Servo Trim Calibration
int trim[4] = {0, 0, 0, 0};

🍎 Mac TTS — speak via Mac voice (Hindi / English)
Your Mac synthesises the speech using a high-quality neural voice, then sends it to the robot at full volume.
For Hindi pick Lekha or Kanya. For Hinglish / Indian English pick Rishi. Needs ffmpeg on the Mac (brew install ffmpeg) — or use the shell script mac_tts.sh directly.

Help me sound

        
On → plays HelpmeSound.wav at full volume 2 s after the scared face

      

      
    

    

      Place the robot in its normal standing position and tap
      Calibrate Now. The robot samples ~3 s of readings to
      learn what “at rest” feels like — then zeroes every axis
      against it, so the bars below read 0 and the cube sits square on its neutral
      face however the IMU is mounted. Lift detection uses that actual resting gravity
      vector, not a hardcoded constant.


      You only need this once. After every scare the robot re-learns
      its resting pose automatically from wherever it ends up, so it stays armed
      without you touching this button again.
